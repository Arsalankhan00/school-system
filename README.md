# School Management System

A full-stack web-based application designed to streamline and automate the administrative tasks of educational institutions. Built using PHP, MySQL, HTML5, CSS3, JavaScript, and Bootstrap 5.

## Features

### 1. Student Admission Module
- Add, update, and delete student profiles with personal and academic details
- Enrollment into selected courses with admission history and status tracking
- Search and filter students by name, admission number, department, or status

### 2. Teacher Module
- Teacher registration and assignment to specific subjects
- Manage teaching loads and view assigned course responsibilities
- Search and filter teachers by name, department, or status

### 3. Course Allocation Module
- Assign courses to both teachers and students based on curriculum requirements
- Add, edit, and remove courses linked with departments
- Department management with full CRUD operations

### 4. Fee Management Module
- Track student fee records, payment history, and generate payment receipts
- Fee structure setup by fee type, amount, department, and academic year
- Financial reporting with date range filters and summary statistics

### 5. Class Time Schedule Module
- Create and manage class timetables for students and teachers
- Automatic scheduling conflict detection and prevention
- Visual timetable grid view by day of the week
